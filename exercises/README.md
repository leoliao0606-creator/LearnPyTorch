# 练习说明

这个目录把 notebook 里的练习抽成独立文件，方便你在脱离教学上下文的情况下单独完成一遍。

## 目录结构

- `by_notebook/`：按 notebook 编号整理的练习版
- `solutions/`：对应的参考答案

## 当前覆盖范围

这一轮优先抽取了学习主线里价值最高的一批练习：

- `01_03_autograd`
- `01_05_building_models_with_nn_module`
- `01_07_training_loop`
- `02_02_cnn_basics`
- `03_02_lstm_intro`
- `04_02_debugging_playbook`
- `05_01_capstone_tabular_classification`
- `05_02_capstone_text_classification`

## 后续扩展规则

如果后面要继续补齐，就保持同样的命名方式，把剩余 notebook 里的练习逐步抽出来即可。
